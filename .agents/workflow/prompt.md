# Task Workflow

Follow this workflow for any implementation task.

- Read [`INDEX.md`](../../INDEX.md) to understand the project structure, then
  read [`AGENTS.md`](../../AGENTS.md) and any rule files it routes you to.
- Understand the project and the scope of work.
- Create a plan.
- Write code section by section. Do not write the entire codebase at once.
- When the code is finished, test it thoroughly.
- If any errors are found, make a plan and fix them.

## Pull Requests

If the user requests a pull request:

- Create a detailed report within the pull request description.
- Specify exactly what was added, deleted, modified, or optimized.
